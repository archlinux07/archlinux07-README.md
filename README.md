Create a user:

```bash
sudo useradd linuxuser
```

Set password:

```bash
sudo passwd linuxuser
```

Create a group:

```bash
sudo groupadd developers
```

Add user to group:

```bash

```

Check current user:

```bash
whoami
```

## 🔐 Linux Permissions

Check permissions:

```bash
ls -l
```

Change permissions:

```bash
chmod 755 script.sh
```

Change ownership:

```bash
sudo chown user:user example.txt
```

Example permission:

```text
-rwxr-xr-x
```

Meaning:

```text
Owner  = rwx
Group  = r-x
Others = r-x
```
